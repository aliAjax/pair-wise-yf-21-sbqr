# hxyfront-62009 地毯修复纹样档案

源提示词编号：2

做一个给手工地毯修复工作室使用的纹样与修复档案前端项目，可以记录地毯产地、年代、结密度、材质、染色类型、破损区域、补线颜色和修复工序。页面需要有纹样局部标记图、修复前后记录、材料色卡、工序进度和按产地筛选的档案列表。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62009

## 纹样对照台

静态档案页已升级为纹样对照台，覆盖以下规则：

- **样本与对称轴**：每块地毯选定纹样样本和对称轴（轴可以半格为单位移动，可穿列正中或落在列边界）。
- **对称参考区**：圈出的破损区域自动镜像找到对称参考区，补线按参考区当次色号走。
- **待核对**：两侧对不上（参考区超出图幅或与破损区重叠）或区域压在轴上时，先标待核对，不能配线。
- **权限**：换样本、改对称轴仅纹样管理员可提交；修复师越权提交会被拒绝并记入操作记录。
- **变更联动**：样本或对称轴一改动，档案转入待重新确认；未开工（已配线）的工序退回待配线，已完成的工序保留当时记录（色号、样本、轴位、完成时间）。
- **持久化**：样本、对称轴、核对结果与工序进度存入 localStorage，关掉页面再打开都还在。
